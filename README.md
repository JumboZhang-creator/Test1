# 沿海台风实况与分级预警平台

面向沿海居民的台风实况信息网站项目，核心目标是让用户在几秒内看懂：

- 台风叫什么
- 台风现在在哪里
- 台风往哪里走、预计何时影响本地
- 当前风力有多大
- 所在地区处于什么预警等级、现在应该做什么

详细产品与实施方案见 [PROJECT_PLAN.md](./PROJECT_PLAN.md)。

## 当前状态

项目处于规划阶段。本仓库暂存放项目计划、后续设计文档和源代码。

## 重要原则

- 预警信息以国家及地方气象、应急、海洋等主管部门正式发布为准。
- 平台不自行替代政府部门发布预警，不把模型预测包装成确定事实。
- 首页优先展示居民需要立即理解和采取行动的信息。
